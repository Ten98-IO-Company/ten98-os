# Contributing to ten98-os

Development has not started. It begins when the work to unify Campaign, Discover and Books is finished. Until then
there is no code to contribute to.

## Before you contribute

1. Read [AGENTS.md](AGENTS.md) and the wiki's [Decisions](https://github.com/Ten98-IO-Company/ten98-os/wiki/Decisions)
   and [Structure](https://github.com/Ten98-IO-Company/ten98-os/wiki/Structure) pages.
2. Read the [Contributor Agreement](CONTRIBUTOR-AGREEMENT.md). The project's licence does not allow changes, so the
   agreement is what permits your contribution.
3. Add this sentence to the description of your pull request:

   > I have read and agree to the ten98-os Contributor Agreement, version 1.

A pull request without that sentence is not merged.

## How to contribute

- Open an issue first for anything larger than a small fix.
- Work on a branch and open a pull request into `main`.
- Documentation changes go to the wiki, not to this repository.

## Security

Do not report a security defect that no release has fixed in an issue, a pull request or the wiki. Report it
privately through the repository's Security tab, as [SECURITY.md](SECURITY.md) describes.
