# ten98-os

One system for the whole business. The OS is the main app. Inside it sit six apps (Marketing, Sales, Finance,
Workspace, Groupware core and Websites), and each app is made of modules, which are its features.

**Status:** vision and planning. Nothing is built in this repository yet. Most of Marketing and the core of Finance
work today as the separate apps [Campaign](https://github.com/Ten98-IO-Company/ten98-campaign),
[Discover](https://github.com/Ten98-IO-Company/ten98-discover) and
[Books](https://github.com/Ten98-IO-Company/ten98-books).

## Who it is for

Businesses and agencies that want an app built for each role without separate sign-ins, duplicated records or
several systems to run.
