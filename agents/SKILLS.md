# Skill shortlist

Pick the smallest set of skills for the task before you start. A skill is a packaged set of instructions your tool
may have installed. If your tool does not have one, follow the procedure in [sops/](sops/) alone.

## Rules

- Use at most three skills for one task.
- Read a skill's instructions before you use it.
- Choose again when the task changes.
- Do not load every skill to be safe.

## Shortlist

| Task | Skills | Procedure |
|---|---|---|
| Starting any task | None | [start-a-task](sops/start-a-task.md) |
| Splitting a task that is too large | None | [split-and-delegate](sops/split-and-delegate.md) |
| Building a module | `ponytail` for the smallest complete build | [build-a-module](sops/build-a-module.md) |
| A new screen, layout or visual design | `frontend-design` | [build-a-module](sops/build-a-module.md) |
| React and TanStack code | `vercel-react-best-practices` | [build-a-module](sops/build-a-module.md) |
| Checking a screen for usability and accessibility | `web-design-guidelines` | [review-a-change](sops/review-a-change.md) |
| A bug fix or a change in behaviour | `test-driven-development`, `systematic-debugging`, `verification-before-completion` | [build-a-module](sops/build-a-module.md) |
| A change that crosses screen, server and database | An API drift check | [build-a-module](sops/build-a-module.md) |
| Reusing a function from a Ten98 app | `ponytail` | [reuse-a-ten98-function](sops/reuse-a-ten98-function.md) |
| Studying a shipped product that has no source | `reverse-engineer-anything` | [reuse-a-ten98-function](sops/reuse-a-ten98-function.md) |
| Adding a public package | None | [add-a-dependency](sops/add-a-dependency.md) |
| Ledger, statement or reconciliation logic | `financial-statements`, `reconciliation` | [build-a-module](sops/build-a-module.md) |
| Unclear scope, or a fresh read before handing off | The matching `paperthin` skill | [finish-and-hand-off](sops/finish-and-hand-off.md) |
| Reviewing someone else's change | A fresh agent, or a review plugin | [review-a-change](sops/review-a-change.md) |
| Writing or changing a procedure | `process-doc` | None |
| Wiki pages and specifications | `doc-coauthoring` | None |

Marketing and sales writing skills, such as `campaign-plan` and `content-creation`, are for sample content only.
They are not for building the product.
